# 同款判定标准详解（含正反例）

> 配套 `SKILL.md`，这里展开「怎么判断」的细节和常见误判。

---

## 一、核心原则

**同款 = 同一个产品，只是卖的人/颜色/规格不同。**

判断时只问一句：**「如果这两个东西摆在一起，买家会不会认为是一模一样的商品？」**

- 会 → 同款
- 不会，但很像 → **不同款**（相似款不算）

---

## 二、5 个必须一致的维度

### ① 结构形态

**看什么**：
- 整体形状（方形/圆形/异形/立体）
- 层数（单层/多层）
- 开合方式（翻盖/抽绳/按扣/拉链/磁吸）
- 有没有"骨架"（硬的 vs 软的）

| 正例（同款）| 反例（不同款）|
|---|---|
| 立式方形袋 + 三角折顶 | 抽绳收口的软袋 |
| 圆形硅胶扣带 | 长条形尼龙扎带 |
| 带盖方形收纳盒 | 敞口篮子 |

### ② 核心功能件

**这是最硬的区分点。** 功能件变了，使用体验就完全变了。

| 功能件 | 同类吗 |
|---|---|
| **按扣（snap）** | 只有按扣之间算 |
| **拉链（zipper）** | 只有拉链之间算 |
| **抽绳（drawstring）** | 只有抽绳之间算 |
| **魔术贴（hook and loop）** | 只有魔术贴之间算 |
| **绑带（strap/tie）** | 只有绑带之间算 |
| **吸盘（suction）** | 只有吸盘之间算 |

**⚠️ 关键**：**按扣 ≠ 拉链 ≠ 抽绳**，三者互相都不是同款。

### ③ 使用方式

| 用法 | 同类吗 |
|---|---|
| 挂（hang）| 只有挂式之间算 |
| 夹（clip）| 只有夹式之间算 |
| 贴（stick）| 只有贴式之间算 |
| 摆（place）| 只有摆放式之间算 |
| 套（slip on）| 只有套式之间算 |
| 穿（wear）| 只有穿戴式之间算 |

**例**：水龙头挂式置物架 ≠ 台面摆放式置物架（虽然都是置物架）

### ④ 关键识别特征

**每个产品都有一个"一眼认出"的特征**，这个特征是买家区分的依据。

| 产品 | 关键特征 |
|---|---|
| 土豆保鲜袋 | **三角折顶 + 深棕顶盖** |
| 小鸟榨汁器 | **小鸟造型 + 鸟嘴出汁** |
| 圣诞鹿耳罩 | **鹿角 / 鹿斑纹** |
| 篮球洗衣篮 | **篮板 + 篮筐造型** |

**如果关键特征不同 → 不是同款**（哪怕其他都一样）。

### ⑤ 材质大类

| 材质 | 同类吗 |
|---|---|
| 布料（fabric/cotton/canvas）| 只有布料之间算 |
| 硅胶（silicone）| 只有硅胶之间算 |
| 金属（stainless steel/aluminum）| 只有金属之间算 |
| 网眼（mesh）| 只有网眼之间算 |
| 塑料（plastic/ABS）| 只有塑料之间算 |

**⚠️ 注意**：细分的材质差异（纯棉 vs 涤纶，304 不锈钢 vs 201）**算同款**；但**大类不同（布料 vs 网眼）不算**。

## 三、5 个允许不同的维度（老板明确）

| 维度 | 说明 | 举例 |
|---|---|---|
| **颜色** | 完全不影响 | 红的 vs 蓝的 = 同款 |
| **图案/印花** | 完全不影响 | 有花纹 vs 纯色 = 同款 |
| **尺寸** | 完全不影响 | 小号 vs 大号 = 同款 |
| **几件装** | 完全不影响 | 1 件 vs 3 件 vs 12 件 = 同款 |
| **赠品** | 完全不影响 | 送手套 vs 不送 vs 送别的 = 同款 |

**老板原话**：
> 「不管送不送赠品，送什么样的赠品都算同款！」
> 「不管是几件装，只要样子一样就是同款！记住！牢记！」

---

## 四、容易误判的 6 种情况

### ① 标题一样但产品不一样
有些卖家会堆砌关键词，标题写得很像但产品不同。
**→ 以主图为准，不看标题。**

### ② 主图一样但其实是盗图
有卖家盗用别家的图卖自己的货（货不对板）。
**→ 这种情况判为"同款"没错，因为买家看到的就是同款图，但要在报告里标注"疑似盗图"。**

### ③ 结构相似但功能件不同
比如都是"袋子"，一个是按扣，一个是拉链。
**→ 不同款。**

### ④ 材质相近但大类不同
布料 vs 无纺布（non-woven）→ **都算布料类，同款**。
布料 vs 网眼 → **不同款**。

### ⑤ 附件不同但主体一样
主体相同，一个有额外配件（如送手套）。
**→ 同款**（老板明确说了）。

### ⑥ 尺寸差异巨大
比如 20cm 的 vs 100cm 的。
**→ 按老板规则算同款，但要在报告里标注尺寸差异（买家可能不认为是同一用途）。**

## 五、判断流程（实操）

对每个候选：

```
1. 看主图 → 判断 ①结构形态 是否一致
   - 不一致 → 不同款，结束

2. 判断 ②核心功能件 是否一致
   - 不一致 → 不同款，结束

3. 判断 ③使用方式 是否一致
   - 不一致 → 不同款，结束

4. 判断 ④关键识别特征 是否一致
   - 不一致 → 不同款，结束

5. 判断 ⑤材质大类 是否一致
   - 不一致 → 不同款，结束

6. 全部一致 → 同款 ✅
```

**任何一步不一致就停**，不用看完 5 步。

## 六、输出时必须写「判定理由」

**格式**：
```
✅ 同款：B0HGQXFNR9 — 按扣 + 三角折顶 + 方形立式 + 布料，全部一致（3 袋无手套，件数差异不影响）
❌ 不同款：B01HHDK44Y — 抽绳收口（不是按扣），结构形态不同
❌ 不同款：B0CKT6Z46M — 网眼材质（不是布料）
```

**为什么必须写**：老板要能核验我的判断，不写理由他就没法判我对不对。

## 七、能力边界（诚实说）

| 能做 | 做不到 |
|---|---|
| ✅ 判断结构、功能件、使用方式、材质大类 | ❌ 判断缝线工艺、扣子材质、内部结构 |
| ✅ 用多角度（主图+副图）交叉确认 | ❌ 只有 1 张模糊图时会误判 |
| ✅ 给出可核验的判断理由 | ❌ 判断"是不是同一个工厂出的"（这要看货源，不是看图）|

**规则**：**不确定的标 `?`**，别硬判。让老板复核。

---

## 八、和「找竞品」的区别

| | 找竞品 | 找同款 |
|---|---|---|
| 目的 | 了解市场 | 比价格、看竞争密度 |
| 范围 | 同类目所有商品 | **只要结构一致的** |
| 判定 | 宽松 | **严格（5 维度）** |
| 用途 | 选品、写文案 | **定价、判断竞争激烈程度** |

**老板要的是「找同款」，不是「找竞品」。** 这两个必须分清。
